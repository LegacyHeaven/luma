# Examples

Reference code for building your own Luma themes and plugins. Everything here is documentation only - it does not ship with Luma and is not listed in the in-app marketplace.

- [`themes/blank-theme-example/`](themes/blank-theme-example/) - a minimal grayscale theme (no glow, gradients, or animation), a clean starting point instead of copying the colorful default.
- [`plugins/example-plugin/`](plugins/example-plugin/) - a minimal `@bang` plugin showing the `LumaPlugin.register` API.

See the wiki's "Creating a Theme" and "Writing a Plugin" developer guides for the full format and how to actually load one of these into a running copy of Luma.
