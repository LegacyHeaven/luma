Advanced logging

Off by default, and fully inert while off - nothing is recorded or written to disk. Turn it on and LUMA records every notable thing it does (every command it runs, search submitted, results opened, config saved, errors) at a much higher level of detail, both in the console below and in a rotating log file on disk - plus live RAM/process info, so a bug can be diagnosed without a terminal. See the wiki's "Logging & diagnostics" page for the exact format, useful for anyone building their own version of LUMA. You found this section by holding Shift+L on this page - it'll stay revealed once enabled below.
