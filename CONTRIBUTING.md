# Contributing

Building from source, project layout, writing a plugin or theme, and how
LUMA works under the hood are all covered in the
[Developer Guide](../../wiki/Contributing) on the wiki.

Before opening a pull request, please read the
[Code of Conduct](CODE_OF_CONDUCT.md).

Bug or feature idea? Open one from
[Issues](../../issues/new/choose). Found a security problem? See
[SECURITY.md](SECURITY.md) instead of opening a public issue.
